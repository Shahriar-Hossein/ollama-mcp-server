## Decision and next step

8192 is a practical ordinary-delegation request default: it leaves 40784
input allowance instead of 23976 under the current byte-bound check and
does not truncate these short scouts or the tested summary. It does not fix
source-selection or summary-fidelity errors, and it is insufficient for the
tested long inventory. Use a larger explicit ceiling for such tasks when
input fits; 16384 has historical evidence but has not been retested on H.

Next: implement documented tool-specific output reserves with overrides,
then test representative summaries/delegations and tighten input accounting.
This run did not test maximum 50K capacity or identify an optimal ceiling.
Saved model settings and production defaults remain unchanged.
