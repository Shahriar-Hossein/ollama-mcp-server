# H at 64 Ki context with a 16 Ki output ceiling — 2026-10-03

This repeats the [50K/8192 tests](2026-10-03-h-8k-output.md) using the same
model with explicit `num_ctx=65536`, `num_predict=16384` overrides. Saved
model settings and production defaults are unchanged.

## Protocol and placement

- Same H weights, template and saved sampling; thinking off.
- Empty daemon before clean preload; q4_0 KV cache, Flash Attention and one
  inference slot verified from the effective service environment.
- Preload reports **15% CPU / 85% GPU** at 65536 context. The 50K run was
  entirely on GPU. CPU offload is retained and measured in this test rather
  than excluded; it reproduces the earlier clean 64 Ki placement result.
- Three sequential warmed repetitions of the same four-question scout
  fixture, the same 30000-character summary through `summarize_output`, and
  the same historical 36-record direct `/api/generate` inventory request.
- Scout/summary HTTP deadline: 120 seconds per call. Inventory deadline:
  600 seconds. No timeout reruns. Preloading is excluded from task timings.
- Prompt reuse affects timings. Context and output ceiling both changed;
  this comparison cannot isolate their individual effects or establish a
  speed difference from repeated paired trials.
- Raw settings, requests, outputs, metrics, SHA, placement and GPU samples:
  ignored `benchmark-data/qwen-context/h-64k-16k-2026-10-03/`. One detached
  locked supervisor ran the sequential tests.
