# Experimental

Preserved advanced and autonomous work that is intentionally outside the
project's current supported focus.

- `explorer/` contains semantic search, Git history, verification, knowledge,
  framework adapters, and the complete pipeline.
- `tools/` contains their optional MCP registrations and the model-driven local
  explorer.
- `workers/` contains autonomous Git-writing workers and their shared allowlist.
- `benchmarks/` contains research entry points.

Nothing here is loaded by the default MCP configuration. Return only when a
specific feature flag and concrete need justify it.
